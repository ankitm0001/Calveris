# Calveris Limited website

Production website for [calveris.co.uk](https://calveris.co.uk), built with TanStack Start, React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production check

```bash
npm run lint
npm run build
```

The project is configured for Cloudflare deployment. Pushing changes to the connected GitHub branch should trigger the existing deployment workflow.
